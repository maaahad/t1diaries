InRange · backend
Rust · axum · async-graphql · sqlx · Postgres

Every backend deliverable for the eight-week MVP, written as something you can build against: what exists at the end of the week, what the schema looks like, what the code looks like, and what has to be true before it counts as done. Feature IDs match the MVP plan.

Shape

One binary, two modes, one database

The whole backend compiles to a single Rust binary that starts either as the HTTP/GraphQL server or as the ingestion worker, chosen by a subcommand. Shared domain code lives in a library crate that both modes link. This is the right shape for one developer: one build, one deploy pipeline, one set of types, and no network boundary to debug at 11pm.

Decisions taken up front

Decision Choice Why, and what it costs
Process model One binary, subcommands Halves the deploy surface. Cost: the worker and API scale together, which is irrelevant at MVP volume.
Database access sqlx with compile-time checked queries Query errors surface at cargo check. Cost: needs a live database or a committed .sqlx offline cache in CI.
Search Postgres FTS + pg_trgm No second datastore to run, back up or keep in sync. Cost: no typo tolerance beyond trigrams, no semantic ranking. Revisit past ~500k documents.
Cache and queue Postgres tables with SKIP LOCKED No Redis in the MVP. Postgres is a perfectly good queue at this scale and one less thing to operate.
Sessions Server-side, opaque token in a cookie Instant revocation, no JWT expiry gymnastics, trivial "sign out everywhere". Cost: a database lookup per request, mitigated by an in-process cache.
API style GraphQL only, no REST except webhooks and feeds One schema, generated TypeScript types, no drift. Cost: you must handle depth and complexity limits yourself — see the API tab.
IDs UUIDv7 in the database, opaque global IDs in GraphQL Time-ordered so index locality stays good, while the API never leaks a raw primary key.
Timestamps timestamptz everywhere, UTC in code No exceptions. Local time exists only in the browser.
Migrations sqlx migrate, forward-only, applied on boot Every migration must be safe to run against a live database with the previous version still serving.

Conventions

Module rules

  • model.rs holds plain structs mapping to rows. No behaviour beyond simple constructors.
  • repo.rs is the only place sqlx appears. Every function takes an executor so it composes into transactions.
  • service.rs holds business rules and orchestrates repos. It returns Result<T, CoreError>.
  • GraphQL types in api/graphql/ wrap core models and never re-declare fields the database owns.

Naming and style

  • Repo functions read as SQL intent: insert_story, find_story_by_slug, list_items_after.
  • Service functions read as user intent: publish_story, approve_item, revoke_all_sessions.
  • Typed ID newtypes (StoryId, UserId) so a story ID cannot be passed where a user ID is expected.
  • #![forbid(unsafe_code)] in every crate. Clippy pedantic on, with documented allows.

src/main.rs — the whole binary
use clap::{Parser, Subcommand};
            use inrange_core::{config::Config, db, telemetry};

            #[derive(Parser)]
            #[command(name = "inrange")]
            struct Cli {
            #[command(subcommand)]
            command: Command,
            }

            #[derive(Subcommand)]
            enum Command {
            /// Run the HTTP + GraphQL server.
            Serve,
            /// Run the ingestion and maintenance worker.
            Worker,
            /// Apply pending migrations and exit.
            Migrate,
            /// Print the GraphQL SDL to stdout (used by frontend codegen).
            ExportSdl,
            }

            #[tokio::main]
            async fn main() -> Result<(), Box<dyn std::error::Error>> {
            let config = Config::from_env()?; // fails fast, before anything binds
            telemetry::init(&config)?; // tracing subscriber + OTEL exporter

            let pool = db::connect(&config.database).await?;
            db::migrate(&pool).await?; // safe to run on every boot

            match Cli::parse().command {
            Command::Serve => inrange_api::serve(config, pool).await?,
            Command::Worker => inrange_worker::run(config, pool).await?,
            Command::Migrate => tracing::info!("migrations applied"),
            Command::ExportSdl => println!("{}", inrange_api::graphql::sdl()),
            }
            Ok(())
            }
crates/core/src/error.rs — one error type, mapped once
use thiserror::Error;

            #[derive(Debug, Error)]
            pub enum CoreError {
            #[error("not found")]
            NotFound,

            #[error("not permitted")]
            Forbidden,

            #[error("authentication required")]
            Unauthenticated,

            /// User-correctable. `field` is the input path the client should highlight.
            #[error("{message}")]
            Validation { field: &'static str, message: String },

            #[error("conflict: {0}")]
            Conflict(String),

            #[error("rate limited, retry after {retry_after_secs}s")]
            RateLimited { retry_after_secs: u64 },

            /// Anything the caller cannot act on. Logged in full, never shown in full.
            #[error("internal error")]
            Internal(#[from] anyhow::Error),

            #[error("internal error")]
            Database(#[from] sqlx::Error),
            }

            impl CoreError {
            /// Stable machine-readable code. The frontend switches on this, never on
            /// the message text.
            pub fn code(&self) -> &'static str {
            match self {
            CoreError::NotFound => "NOT_FOUND",
            CoreError::Forbidden => "FORBIDDEN",
            CoreError::Unauthenticated => "UNAUTHENTICATED",
            CoreError::Validation { .. } => "VALIDATION",
            CoreError::Conflict(_) => "CONFLICT",
            CoreError::RateLimited { .. } => "RATE_LIMITED",
            CoreError::Internal(_) | CoreError::Database(_) => "INTERNAL",
            }
            }

            pub fn is_internal(&self) -> bool {
            matches!(self, CoreError::Internal(_) | CoreError::Database(_))
            }
            }

crates/core/src/db.rs — pool, migrations, health 
use sqlx::postgres::{PgPool, PgPoolOptions};
            use std::time::Duration;
            use secrecy::ExposeSecret;

            pub async fn connect(cfg: &crate::config::DatabaseConfig) -> Result<PgPool, sqlx::Error> {
            PgPoolOptions::new()
            .max_connections(cfg.max_connections)
            .min_connections(2)
            .acquire_timeout(Duration::from_secs(5))
            .idle_timeout(Duration::from_secs(300))
            .max_lifetime(Duration::from_secs(1800))
            .test_before_acquire(true)
            .connect(cfg.url.expose_secret())
            .await
            }

            /// Embedded at compile time from ./migrations, so the deployed artefact
            /// carries its own schema and there is no separate migration step to forget.
            pub async fn migrate(pool: &PgPool) -> Result<(), sqlx::migrate::MigrateError> {
            sqlx::migrate!("./migrations").run(pool).await
            }

            pub async fn is_healthy(pool: &PgPool) -> bool {
            sqlx::query_scalar::<_, i32>("SELECT 1")
            .fetch_one(pool)
            .await
            .is_ok()
            }
Why this layout survives contactWhen week 6 gets tight, the temptation is to write SQL directly in a resolver "just this once". The crate boundary makes that impossible rather than merely discouraged: api does not depend on sqlx at all, so the shortcut does not compile.
Deliverable

Data model and migrations

Postgres 16. Constraints are enforced in the database rather than in application code, because the worker and the API both write and only one of them is under test at any given moment.

B-01

Extensions and conventions

Week 1
  • UUIDv7 primary keys generated in Rust, not in the database, so an insert's ID is known before the round trip.
  • Every table carries created_at and updated_at as timestamptz, maintained by a trigger.
  • Soft deletion only where content moderation needs it; everything else is a hard delete.
  • Enumerations as Postgres enum types where the set is closed and stable, as lookup tables where editors may extend it.

CREATE EXTENSION IF NOT EXISTS pg_trgm;
                CREATE EXTENSION IF NOT EXISTS unaccent;

                -- Keeps updated_at honest without relying on every code path remembering.
                CREATE OR REPLACE FUNCTION set_updated_at() RETURNS trigger AS $$
                BEGIN
                NEW.updated_at = now();
                RETURN NEW;
                END;
                $$ LANGUAGE plpgsql;

                impl IntoFieldError for CoreError {
                fn into_field_error(self) -> FieldError {
                let code = self.code();

                if self.is_internal() {
                // Full detail to the log, correlation id to the client, nothing else.
                let request_id = tracing::Span::current()
                .field("request_id")
                .map(|f| f.to_string())
                .unwrap_or_default();
                tracing::error!(error = ?self, code, "unhandled internal error");
                return FieldError::new("Something went wrong on our side.")
                .extend_with(|_, e| {
                e.set("code", code);
                e.set("requestId", request_id);
                });
                }

                let message = self.to_string();
                let field = match &self {
                CoreError::Validation { field, .. } => Some(*field),
                _ => None,
                };
                FieldError::new(message).extend_with(|_, e| {
                e.set("code", code);
                if let Some(f) = field { e.set("field", f); }
                if let CoreError::RateLimited { retry_after_secs } = &self {
                e.set("retryAfter", *retry_after_secs);
                }
                })
                }
                }

Keyset pagination

Offset pagination breaks on a feed that is constantly gaining rows at the head: readers see duplicates and miss items. Keyset cursors on (published_at, id) are stable and index-friendly, and the composite index defined in B-04 serves them without a sort.

use base64::{engine::general_purpose::URL_SAFE_NO_PAD as B64, Engine};
                use chrono::{DateTime, Utc};
                use uuid::Uuid;

                #[derive(Debug, Clone, Copy)]
                pub struct Cursor { pub at: DateTime<Utc>, pub id: Uuid }

                impl Cursor {
                pub fn encode(&self) -> String {
                B64.encode(format!("{}|{}", self.at.timestamp_micros(), self.id))
                }

                pub fn decode(raw: &str) -> Result<Self, crate::error::CoreError> {
                let invalid = || crate::error::CoreError::Validation {
                field: "after",
                message: "That cursor is not valid. Reload the list to start again.".into(),
                };
                let bytes = B64.decode(raw).map_err(|_| invalid())?;
                let text = String::from_utf8(bytes).map_err(|_| invalid())?;
                let (ts, id) = text.split_once('|').ok_or_else(invalid)?;
                Ok(Cursor {
                at: DateTime::from_timestamp_micros(ts.parse().map_err(|_| invalid())?)
                .ok_or_else(invalid)?,
                id: id.parse().map_err(|_| invalid())?,
                })
                }
                }

                /// Always fetch limit + 1 and use the extra row to answer has_next_page
                /// without a second COUNT query.
                pub const MAX_PAGE: i64 = 50;
                pub fn clamp(first: Option<i32>) -> i64 {
                first.unwrap_or(20).clamp(1, MAX_PAGE as i32) as i64
                }

                use rand::rngs::OsRng;

                /// 19 MiB, 2 passes, 1 lane — the OWASP-recommended Argon2id baseline.
                /// Tune upward on the production instance until hashing takes ~100 ms.
                fn argon() -> Argon2<'static> {
                Argon2::new(
                Algorithm::Argon2id,
                Version::V0x13,
                Params::new(19 * 1024, 2, 1, None).expect("valid argon2 params"),
                )
                }

                pub fn hash(password: &str) -> Result<String, CoreError> {
                let salt = SaltString::generate(&mut OsRng);
                argon()
                .hash_password(password.as_bytes(), &salt)
                .map(|h| h.to_string())
                .map_err(|e| CoreError::Internal(anyhow::anyhow!("hash failed: {e}")))
                }

                pub fn verify(password: &str, encoded: &str) -> bool {
                // Hashing is CPU-bound; callers run this on a blocking thread so one login
                // attempt cannot stall the async runtime.
                PasswordHash::new(encoded)
                .map(|parsed| argon().verify_password(password.as_bytes(), &parsed).is_ok())
                .unwrap_or(false)
                }

                .gzip(true)

                pub async fn conditional_get(
                &self,
                url: &Url,
                etag: Option<&str>,
                last_modified: Option<&str>,
                ) -> anyhow::Result<FetchOutcome> {
                guard_public_address(url).await?; // SSRF: no private or link-local targets

                let host = url.host_str().unwrap_or_default().to_owned();
                let sem = self.per_host
                .entry(host)
                .or_insert_with(|| Arc::new(Semaphore::new(1)))
                .clone();
                let _permit = sem.acquire().await?; // one request per host at a time

                let mut req = self.inner.get(url.clone());
                if let Some(t) = etag { req = req.header(header::IF_NONE_MATCH, t); }
                if let Some(m) = last_modified { req = req.header(header::IF_MODIFIED_SINCE, m); }

                let res = req.send().await?;
                if res.status() == StatusCode::NOT_MODIFIED {
                return Ok(FetchOutcome::NotModified); // the cheap, common case
                }
                if res.status() == StatusCode::TOO_MANY_REQUESTS {
                let wait = res.headers().get(header::RETRY_AFTER)
                .and_then(|v| v.to_str().ok()).and_then(|v| v.parse().ok())
                .unwrap_or(3600);
                anyhow::bail!("rate limited by host, retry after {wait}s");
                }

                let status = res.status().as_u16();
                let etag = header_string(&res, header::ETAG);
                let last_modified = header_string(&res, header::LAST_MODIFIED);
                // Cap the body: a misbehaving source must not exhaust worker memory.
                let body = read_capped(res, 8 * 1024 * 1024).await?;
                Ok(FetchOutcome::Fetched { body, etag, last_modified, status })
                }
                }

                /// Exponential backoff with a ceiling; five consecutive failures pause the
                /// source and raise it in the health dashboard rather than retrying forever.
                pub fn backoff_interval(base: Duration, failures: i16) -> Duration {
                let factor = 2u32.saturating_pow(failures.clamp(0, 6) as u32);
                std::cmp::min(base * factor, Duration::from_secs(24 * 3600))
                }

                pub fn canonicalise(input: &Url) -> Url {
                let mut url = input.clone();

                url.set_fragment(None);
                if let Some(host) = url.host_str() {
                let host = host.to_ascii_lowercase();
                let host = host.strip_prefix("www.").unwrap_or(&host).to_owned();
                let _ = url.set_host(Some(&host));
                }
                if matches!(url.scheme(), "http") { let _ = url.set_scheme("https"); }

                let kept: Vec<(String, String)> = url.query_pairs()
                .filter(|(k, _)| {
                let k = k.to_ascii_lowercase();
                !TRACKING_EXACT.contains(&k.as_str())
                && !TRACKING_PREFIXES.iter().any(|p| k.starts_with(p))
                })
                .map(|(k, v)| (k.into_owned(), v.into_owned()))
                .collect();

                url.set_query(None);
                if !kept.is_empty() {

                // Sorted, so parameter order cannot create a phantom duplicate.
                let mut sorted = kept; sorted.sort();
                for (k, v) in sorted { q.append_pair(&k, &v); }
                }

                let path = url.path().trim_end_matches('/').to_owned();
                url.set_path(if path.is_empty() { "/" } else { &path });
                url
                }

/// 64-bit SimHash over word shingles. Near-identical headlines land within a
                /// small Hamming distance of each other even when outlets reword the lede.
                pub fn simhash(text: &str) -> u64 {
                let mut weights = [0i32; 64];
                for token in normalise_tokens(text).windows(2).map(|w| w.join(" ")) {
                let h = seahash::hash(token.as_bytes());
                for bit in 0..64 {
                if h >> bit & 1 == 1 { weights[bit] += 1 } else { weights[bit] -= 1 }
                }
                }
                weights.iter().enumerate()
                .filter(|(_, w)| **w > 0)
                .fold(0u64, |acc, (i, _)| acc | 1 << i)
                }

                pub fn hamming(a: u64, b: u64) -> u32 { (a ^ b).count_ones() }

                /// Resolution order matters: a strong identifier always beats a fuzzy match.
                pub async fn resolve_identity(
                exec: impl PgExecutor<'_>,
                raw: &RawItem,
                canonical: &Url,
                ) -> Result<Identity, CoreError> {
                if let Some(doi) = &raw.doi {
                if let Some(id) = repo::find_by_doi(exec, doi).await? { return Ok(Identity::Existing(id)); }
                }
                if let Some(pmid) = &raw.pmid {
                if let Some(id) = repo::find_by_pmid(exec, pmid).await? { return Ok(Identity::Existing(id)); }
                }
                if let Some(id) = repo::find_by_canonical_url(exec, canonical.as_str()).await? {
                return Ok(Identity::Existing(id));
                }

                // Fuzzy: same story, different outlet. Restrict to a 72-hour window so an
                // annual "study finds" headline does not collapse into last year's.
                let hash = simhash(&format!("{} {}", raw.title, raw.excerpt.as_deref().unwrap_or("")));
                let candidates = repo::find_recent_by_simhash_window(
                exec, hash, raw.published_at - Duration::hours(72), raw.published_at + Duration::hours(72),
                ).await?;

                if let Some(best) = candidates.into_iter()
                .map(|c| (hamming(hash, c.simhash as u64), c.id))
                .filter(|(d, _)| *d <= 3) // tuned against a labelled sample
                .min_by_key(|(d, _)| *d)
                {
                return Ok(Identity::Existing(best.1));
                }
                Ok(Identity::New { simhash: hash })
                }

                upper_bound = EXCLUDED.upper_bound,
                estimate_type = EXCLUDED.estimate_type,
                source_row = EXCLUDED.source_row

                row.value, row.lower, row.upper,
                row.estimate_type as _, row.raw,
                )
                .execute(&mut *tx)
                .await?;
                loaded += 1;
                }

                tx.commit().await?;
                // Skips are reported, never silent. A silently dropped country is a lie
                // told by a chart.
                Ok(LoadReport { dataset_id, loaded, skipped })

pub const MAX_UPLOAD_BYTES: usize = 10 * 1024 * 1024;
                const WIDTHS: [u32; 3] = [480, 960, 1920];

                pub struct Processed { pub variants: Vec<Variant>, pub width: u32, pub height: u32, pub blurhash:
                String }

                pub fn process(bytes: &[u8]) -> Result<Processed, CoreError> {
                if bytes.len() > MAX_UPLOAD_BYTES {
                return Err(CoreError::Validation {
                field: "file",
                message: "Images must be under 10 MB.".into(),
                });
                }

                // Sniff the real format from magic bytes. A filename extension is a claim,
                // not evidence.
                let format = image::guess_format(bytes).map_err(|_| CoreError::Validation {
                field: "file",
                message: "That file is not a JPEG, PNG or WebP image.".into(),
                })?;
                if !matches!(format, ImageFormat::Jpeg | ImageFormat::Png | ImageFormat::WebP) {
                return Err(CoreError::Validation {
                field: "file", message: "Upload a JPEG, PNG or WebP image.".into(),
                });
                }

                // Decoding and re-encoding drops every metadata block, including GPS
                // coordinates that would otherwise reveal a contributor's home.
                let img = image::load_from_memory_with_format(bytes, format)
                .map_err(|e| CoreError::Internal(e.into()))?;
                let (width, height) = (img.width(), img.height());

                let variants = WIDTHS.iter()
                .filter(|w| **w <= width.max(WIDTHS[0]))
                .map(|w| {
                let resized = img.resize(*w, u32::MAX, image::imageops::FilterType::Lanczos3);
                let mut buf = Vec::new();
                resized.write_to(&mut Cursor::new(&mut buf), ImageFormat::WebP)?;
                Ok(Variant { width: *w, bytes: buf, content_type: "image/webp" })
                })
                .collect::<Result<Vec<_>, image::ImageError>>()
                .map_err(|e| CoreError::Internal(e.into()))?;

                Ok(Processed { variants, width, height, blurhash: blurhash_of(&img) })
                }
  • Media is served from a separate origin with Content-Disposition and a restrictive CSP, so a crafted file cannot execute in the app's origin.
  • Orphaned uploads (never attached to a story within 24 hours) are swept by a housekeeping job.
  • Alt text is required by the publish mutation, not by the form alone.

                AND s.search_tsv @@ websearch_to_tsquery('english_unaccent', $1)
                ORDER BY rank DESC, s.published_at DESC
                LIMIT $2
                "#,
                query, limit

                .await?;

                if !hits.is_empty() { return Ok(hits); }

                similarity(s.title, $1) AS rank,
                s.dek AS snippet
                FROM stories s
                WHERE s.status = 'published' AND s.title % $1

                LIMIT $2
                "#,
                query, limit
                )
                .fetch_all(exec)
                .await

Launch checklist

  • Migrations applied and reversible by a forward migration, never by a manual edit.
  • A restore from last night's backup rehearsed into a scratch database, with the row count verified.
  • Alert routing tested by deliberately breaking a source in staging.
  • Rate limits verified against a scripted burst.
  • Security headers checked against the deployed origin, not against localhost.
  • Every aggregated source has a recorded licence note and a contact route for removal requests.
  • Privacy notice, editorial policy and safety page published and linked from every page.
